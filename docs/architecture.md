# Архитектура

Ферма — это два независимых приложения и папка данных:

| Часть | Что это | Технологии |
|---|---|---|
| `backend/` | сервер: телефоны, очередь запусков, сценарии, API | Python 3.9+, FastAPI, uiautomator2, adb |
| `frontend/` | сайт: всё, что видит человек | HTML, CSS, JavaScript без сборки и фреймворков |
| `data/` | рабочие данные фермы | JSON-файлы и артефакты, в git не попадают |

Они общаются только через HTTP: сайт зовёт `/api/*`, сервер отвечает JSON
(и MJPEG-потоком для экранов). Ни одна строка сайта не знает про adb, ни одна
строка сервера — про вёрстку.

## Слои сервера

```
             HTTP
              │
   ┌──────────▼──────────┐
   │  api/               │  тонкие роутеры: разобрать запрос, вызвать сервис,
   │  (FastAPI routers)  │  вернуть JSON. Бизнес-логики здесь нет.
   └──────────┬──────────┘
              │
   ┌──────────▼──────────────────────────────────────────────┐
   │  сервисы                                                 │
   │  devices/registry  — какие телефоны есть, их здоровье    │
   │  devices/runner    — очередь запусков, остановка на HELD │
   │  scenarios, schedule, accounts, deviations, guards       │
   │  context.py (ctx)  — API, которым пользуются сценарии    │
   │  recorder/         — конструктор: шаги ⇄ код             │
   └──────────┬──────────────────────────────────────────────┘
              │
   ┌──────────▼──────────┐
   │  control/ + adb.py  │  единственное место, где говорим с телефоном:
   │  streaming/         │  ввод, приложения, захват экрана, MJPEG
   └──────────┬──────────┘
              │
           телефоны
```

Правило слоёв: **вызовы идут только вниз**. Роутер может звать сервис, сервис —
`control/`, но `control/` никогда не зовёт роутер. Поэтому каждый слой можно
тестировать отдельно, а модули без adb (`ui/`, `obstacle.py`, `deviations.py`,
`recorder/steps.py`, `recorder/codegen.py`) тестируются вообще без телефона.

## Слои сайта

```
index.html            разметка всех разделов (один документ, разделы — <section>)
design/tokens.css     дизайн-токены
css/*.css             стили по разделам
strings/ru.json       тексты
js/i18n.js            t() и подстановка текстов в разметку
js/core.js            общее: api(), toast(), модалки, состояние S
js/<раздел>.js        логика раздела: fleet, pult, jobs, recorder…
js/app.js             навигация, опросы сервера, старт
```

Состояние приложения — один объект `S` (core.js): список телефонов,
запусков, сценариев, открытый телефон. Опросы (`app.js`) раз в несколько
секунд обновляют `S` и перерисовывают только то, что изменилось.

## Как проходит запуск сценария

```
Кнопка «Запустить»  ──▶  POST /api/run  ──▶  runner.submit()
                                                  │  задача в очередь телефона
                                                  ▼
                                    поток телефона берёт задачу
                                                  │
                              DeviceContext (ctx) ◀┘   scenario.run(ctx)
                                     │
            ctx.click / ctx.on_track / ctx.expect_screen …
                                     │
                     не нашли цель / сбились с пути?
                         │                       │
                  стражи и отводы            человек: HELD
                  закрыли окно               «Показать, как быть»
                         │                       │
                         └──── продолжаем ◀──────┘
```

## Куда класть новое

| Хочу добавить | Где |
|---|---|
| действие с телефоном (кнопка, массовое действие) | функция в `ACTIONS`, `backend/farm/api/screen.py` |
| новый API | роутер в `backend/farm/api/`, подключить в `api/__init__.py` |
| логику без HTTP | сервис-модуль в `backend/farm/` (и тест в `backend/tests/`) |
| новый сценарий | `backend/scenarios/<имя>.py` с `run(ctx)` |
| раздел или панель сайта | разметка в `index.html`, логика в `js/<раздел>.js`, стили в `css/` |
| текст | `frontend/strings/ru.json` |
| цвет, размер, отступ | `frontend/design/tokens.css` |

Пошаговые примеры — в [backend.md](backend.md#как-добавить-фичу) и
[frontend.md](frontend.md#как-добавить-фичу).
