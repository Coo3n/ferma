# HTTPS и защита фермы

Ферма управляет телефонами и хранит пароли аккаунтов. Это приложение одного
владельца: обладатель токена получает полный доступ, включая запуск Python-сценариев.

## Обычный запуск на этом компьютере

Адрес: **https://127.0.0.1:8777**. Сервер по умолчанию слушает только loopback.

На Mac один раз:

```bash
brew install mkcert
mkcert -install
./run.sh
```

`mkcert -install` может попросить пароль администратора в терминале. Он добавляет
доверие к локальному центру сертификации, а не отключает проверку сертификатов.
Без этого HTTPS уже шифрует соединение, но браузер не доверяет сертификату:
закончите установку доверия, не обходите предупреждение браузера.

На Windows установите mkcert (`choco install mkcert` или
[официальный релиз](https://github.com/FiloSottile/mkcert/releases)), выполните
`mkcert -install` и откройте `run.bat`. На Linux установка описана в
[инструкции mkcert](https://github.com/FiloSottile/mkcert#installation).
Для Firefox может понадобиться `nss` и повторный `mkcert -install`.

`run.sh` / `run.ps1` создают сертификат для `localhost`, `127.0.0.1`, `::1`
через `backend/tools/setup_https.py`. Файлы лежат в игнорируемой Git папке
`data/tls`; приватный ключ на Unix имеет права `600`, папка — `700`.
CA и её приватный ключ хранятся отдельно в каталоге `mkcert -CAROOT`.
Никому не передавайте `rootCA-key.pem` или `data/tls/key.pem`.

Перевыпустить сертификат до истечения срока:

```bash
.venv/bin/python backend/tools/setup_https.py --renew
./run.sh
```

Свой сертификат: задайте **обе** переменные `FARM_TLS_CERT` и `FARM_TLS_KEY`.
Относительные пути считаются от корня проекта (так же, как `FARM_DATA_DIR`). Отсутствующий, повреждённый или
неподходящий ключ останавливает запуск; отката на HTTP нет. Срок действия,
доверие и соответствие имени проверяет клиент при TLS-соединении.

## Доступ из локальной сети

Открывать сервер в сеть разрешено только с HTTPS и `FARM_TOKEN` минимум
32 символа. Сгенерируйте случайный секрет, а не запоминаемый пароль:

```bash
export FARM_TOKEN="$(.venv/bin/python -c 'import secrets; print(secrets.token_urlsafe(32))')"
.venv/bin/python backend/tools/setup_https.py --renew --host 192.168.1.5
FARM_HOST=0.0.0.0 ./run.sh
```

Замените IP на адрес компьютера с фермой. На клиентском устройстве нужно
установить доверие **только к публичному** `rootCA.pem`; приватный ключ CA
переносить нельзя. Для DNS-имени добавьте его в SAN сертификата через `--host`
и в `FARM_ALLOWED_HOSTS` (имена через запятую, без порта).

API принимает заголовок `X-Farm-Token`. Для браузера пока сохранён старый
вход `https://адрес:8777/?token=СЕКРЕТ`: после проверки немедленный переход на `/`.
Cookie имеет `Secure` (на HTTPS), `HttpOnly`, `SameSite=Strict`, срок в браузере
12 часов. Ответ входа — `no-store`, `no-referrer`, журнал доступа Uvicorn выключен.
Ссылка всё равно может остаться в истории браузера: не отправляйте её в чаты
и не используйте общий браузер. Это общий токен, не отдельные пользовательские
сессии: смена `FARM_TOKEN` отзывает прежние cookie и API-ключи; срок cookie
сам по себе не ограничивает срок действия скопированного токена.

Веб-панель не публикуется автоматически. Для удалённого доступа предпочтительна
частная VPN-сеть. Для публичного сервиса нужны отдельный проект развёртывания,
публичный сертификат, индивидуальная авторизация и внешний reverse proxy/защита
провайдера. Сейчас Uvicorn намеренно не доверяет `X-Forwarded-*`.

## Что блокируется

| Угроза | Механизм |
| --- | --- |
| Перехват HTTP | HTTPS по умолчанию, TLS 1.2+, сетевой HTTP запрещён |
| Пустой/слабый сетевой токен | Отказ при старте и проверка на каждом запросе, включая альтернативный ASGI-запуск |
| Перебор токена | 10 неудачных попыток на IP, пополнение одной попытки за 6 секунд; затем `429` |
| HTTP flood | На IP: 200 запросов/с, начальный запас 400; общий предел 400/с, запас 800 |
| Частые команды | Меняющие запросы: 30/с на IP, запас 60 |
| Истощение соединений | Не больше 256 активных запросов / 128 с одного IP; дополнительно лимит Uvicorn 512 |
| Большой JSON / chunked body | До 32 МиБ до JSON-парсинга, не больше 8 одновременных тел; Content-Length не считается доказательством размера |
| Медленные тела запросов | 30 секунд на обычное тело; у файлов 30 секунд на очередной фрагмент и до 30 минут всего |
| Медленные HTTP-заголовки (Slowloris) | Незавершённые заголовки закрываются через 15 секунд на уровне HTTP-протокола, включая keep-alive |
| Заливка файлов | До 4 одновременных потоковых загрузок; APK/файлы до `FARM_MAX_UPLOAD_MB` (по умолчанию 1024 МиБ), резервные копии до 64 МиБ |
| Раздувание таблицы IP | Состояние rate limiter ограничено 4096 IP, неактивные записи удаляются |
| Подмена IP через заголовки | Лимиты используют сетевого клиента, а не `X-Forwarded-For` |
| CSRF и DNS rebinding | Проверки Host, полного Origin/Referer и Fetch Metadata для API, включая GET с побочными эффектами |
| Clickjacking | `frame-ancestors 'none'` и `X-Frame-Options: DENY` |
| Подгрузка чужих скриптов/плагинов | CSP same-origin, `object-src 'none'`, `base-uri 'none'` |
| Утечка через кэш/ошибки | API и ошибки — `no-store`; непредвиденные исключения не выдаются клиенту целиком |
| Выход за папки / подстановка команд | Существующие проверки путей, белые списки архивов и экранирование shell-аргументов; регрессионные тесты |

Лимиты рассчитаны на одну ферму и десятки экранов: длинный MJPEG-поток занимает
один активный запрос, а не запрос на каждый кадр. Лимиты работают **на процесс**;
запуск нескольких Uvicorn workers для этого приложения не поддерживается.

### SQL-инъекции и XSS

SQL-драйверов и SQL-запросов в текущем сервере нет: данные хранятся в JSON и
файлах. Поэтому SQL-инъекция сейчас не является применимым вектором; фильтр слов
`SELECT`/`DROP` не добавлялся. Если появится база, используйте параметризованные
запросы. В текущем проекте важнее инъекции в генерируемый Python, команды adb
и HTML — их нужно проверять на соответствующих границах.

CSP усиливает защиту, но пока допускает `unsafe-inline`, необходимый существующим
обработчикам интерфейса. Это **не полная защита от XSS**; перевод обработчиков на
`addEventListener` и полный аудит всех HTML-шаблонов — отдельная работа.
Встроенная справка `/docs` и `/redoc` имеет узкое исключение для своих ресурсов
jsDelivr и Google Fonts; основной интерфейс это разрешение не получает.

Rate limiting и тайм-ауты смягчают HTTP-flood и перегрузку приложения, но не
останавливают распределённую атаку, забивающую сетевой канал, или TCP SYN flood.
Эти уровни закрывает VPN,
сетевой firewall и внешний сервис защиты/провайдер, если сервис публикуется.

## Локальная разработка без TLS

```bash
FARM_HTTPS=0 ./run.sh
# Раздельный frontend dev server: оба процесса — только на loopback.
FARM_HTTPS=0 FARM_SERVE_FRONTEND=0 ./run.sh
python3 frontend/dev_server.py
```

Этот режим явный и допускается только на loopback. Не используйте отдельный
`frontend/dev_server.py` для сетевого или защищённого развёртывания.
