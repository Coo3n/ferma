# tools

## seed_repair_demo.py

Панель на временных каталогах с заранее засеянными отклонениями — чтобы
проверить «Починить шаг» в браузере без телефона.

    python3 tools/seed_repair_demo.py [--port 8777]

Настоящие `scenarios/`, `artifacts/`, `network.json`, `devices.json` не
затрагиваются. Временный каталог не удаляется (путь печатается при старте) —
можно осмотреть `demo_login_assets/recipe.json` и `demo_login.py` после
починки, потом стереть вручную. Занятый порт — отказ с понятным сообщением.

Режим hold («Поправить и повторить») так не показать: нужна реальная задача,
держащая устройство. Его покрывает `tests/test_repair_flow_integration.py`.
